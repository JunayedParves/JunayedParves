## 🧰 How I work

1. **Audit before I narrate.** I reconcile every measure to the source before building visuals.
2. **One question per page.** Chart titles state the finding and update when you filter.
3. **Size the recommendation.** Every action comes with an estimated value and the assumption behind it.
4. **BI as code.** Power BI projects are saved as PBIP/TMDL so the model can be reviewed in Git.
